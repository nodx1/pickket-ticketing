## 3. 설계 원칙 (이번 과업에서 지킨 것)

- 운영 동작 불변: 새 기능은 선택해야 켜지고, 기본 정책 가중치는 기존과 비트 단위 동일(회귀 테스트).
- 마이그레이션은 추가만, 기존 컬럼 변경·삭제 없음. 위험한 전환(R-1 UNIQUE)은 기존 데이터가 맞지 않으면 멈춘다.
- 기록은 지울 수 없게: 증명서·Merkle·제재·차단·시계열·연동 원장 모두 append-only 트리거.
- 개인정보 최소화: 공개 데이터는 user_commit·마스킹, 시계열 가명, 원장 마스킹.
- 증빙은 실측으로: 단위 테스트 + 실 PostgreSQL/Redis/TimescaleDB/API 서버 시나리오 + 부하 테스트 + 화면 캡처.
